# Information Security Policy

All laptops use full-disk encryption and must lock automatically after five minutes of inactivity. Multi-factor authentication is mandatory for email, source code repositories and every cloud console.

## Passwords

Passwords must be at least 14 characters long and stored only in the company password manager. Sharing passwords by chat or email is forbidden, even with colleagues.

## Customer data

Customer data may only be processed in approved cloud regions inside the European Union. Personal data must be pseudonymised before it is used for analytics or for training machine learning models, in line with the GDPR.

## Reporting incidents

A lost laptop, a phishing email or any suspected security incident must be reported to the security team within one hour, through the #security-incidents channel or by calling the on-call number.
